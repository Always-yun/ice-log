# 冰迹 · 花滑训练日志

冰迹是一个为花滑爱好者做的训练手账。每次下冰后，记下滑了多久、练了什么、花了多少。等积累了一段时间，再回看第一次掌握一个动作到逐渐熟练的过程。

[下载最新版 ZIP](https://github.com/Always-yun/ice-log/archive/refs/heads/main.zip) · [查看网页文件](https://github.com/Always-yun/ice-log/blob/main/index.html)

## 可以记录什么

| 页面 | 功能 |
| --- | --- |
| 首页 | 记录自主练习或教练课、冰场、冰时、训练笔记和媒体附件。查看本月冰时、次数、训练花费、已记录与已掌握的动作数。 |
| 动作 | 按跳跃、旋转、步法、整活或其他分类查看进度。为每个阶段单独保存照片或视频。 |
| 冰时 | 在月历上查看上冰日期，点日期看当天训练，并查看当月和累计冰时。 |
| 花销 | 汇总训练日志里的场地费和教练费，也能单独记装备费、考级费和其他支出。月卡、年卡计入场地费大类。 |

## 下载试用

1. 下载 ZIP 并解压。
2. 用浏览器打开解压后的 `index.html`。下载版无需注册或安装。
3. 在首页点「记一次上冰」。时长直接填小时，例如 `1.5`。

如果手机的文件管理器只显示静态预览，可试着用浏览器打开文件，或先在电脑上体验。也可以把 `index.html` 部署到静态网页托管服务，再通过链接打开。

## 记录动作进度

在训练日志中勾选「将本次练习动作纳入动作掌握」，然后点「添加动作」，为每个动作选择「练习中」「第一次掌握」「逐渐熟练」或「稳定完成」。

纳入的动作都会计入「已记录」，达到掌握阶段的动作也会计入「已掌握」。同名动作只计一次。想分别配图，直接点「动作」页的阶段卡片，为该阶段添加照片或视频。训练附件留在原日志里。

## 数据与备份

- 训练记录和媒体存于当前浏览器。冰迹不上传这些数据，也不提供跨设备同步。
- 换手机、换浏览器、换网页地址或清除浏览器数据前，可在首页导出备份，再到新环境导入。备份包含训练记录和媒体，请自行保管。
- 头像和昵称单独保存在当前浏览器，不随训练备份迁移。
- 每条训练或动作阶段最多添加 5 个附件，单个文件上限 20 MB。视频回放取决于浏览器支持的格式。
